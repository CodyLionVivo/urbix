# URBIX — Asistente de decisión de movilidad para Lima

Prototipo interactivo desarrollado para el reto "Movilidad accesible para todos" del PMI Student Hackathon (PMI LATAM Conference Lima 2026), alineado con la meta ODS 11.2.

URBIX compara alternativas de transporte en Lima (tiempo, costo, caminata, transbordos, accesibilidad y confianza del dato) y explica siempre el trade-off entre opciones, en vez de decidir por el usuario.

## Correr localmente

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
```
